# Yara AI Ultimate

Your personal AI companion for Android: real AI chat (Gemini / Groq / OpenRouter / OpenAI / Grok / Claude),
Malayalam-Manglish-English voice in & out, background "Yara" wake word with floating reply bubble,
long-term memory, Data Analytics career coach, and a photo studio.

## Get the APK (no PC needed)
1. Create a GitHub repository (e.g. `yara-ai`).
2. Upload EVERYTHING from this folder (keep the hidden `.github` folder and `app/yara-debug.keystore`).
3. Open the **Actions** tab. The build starts by itself (or press **Run workflow**). Takes ~4-6 minutes.
4. When it turns green: open the repo's **Releases** (right side) and download `Yara-AI.apk`
   (or open the run -> Artifacts -> `Yara-AI-apk`).
5. Install on your phone (allow "Install unknown apps"). Updates install over the old version and keep your chats.

## First run
Menu (three dots) -> Settings -> choose *Google Gemini*, paste a free key from https://aistudio.google.com/apikey
-> **Save & test**. Then enter your name and language. Tap the ear icon for "Yara" background listening.
